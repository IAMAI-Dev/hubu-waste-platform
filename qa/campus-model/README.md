# 校园模型重绘验收 · 2026-10-23

按用户截图的六个标识保留点位坐标与相对位置，重新设计建筑形态。建筑与园林为功能示意，并非真实建筑测绘复刻。

- P1 图书馆：双翼阶梯体量、玻璃中庭、屋顶天窗与入口台阶。
- P2 学生宿舍：三排宿舍楼、连续窗带、屋顶设施和院内植栽。
- P3 教学区：围合教学楼、中央庭院与步行空间。
- P4 桃李园食堂：低层餐厅、采光屋顶、入口遮棚与室外座椅。
- P5 运动场：环形分道跑道、足球场地线、球门及看台；场地主体布置在现有收运点东侧，保留西侧服务通道。
- P6 学术交流中心：会议厅、配楼、玻璃连廊及有节奏的屋面结构。

绿化在校园边界内确定性布置，排除建筑区域与道路。所有模型使用 SVG 与既有投影镜头，未增加图片或 3D 库依赖。

验证：1500、768、390 三档宽度 × 深浅两主题；六个模型与 POI ID 一一对应；运动场几何元素存在；无非法坐标、横向溢出或未捕获脚本错误；键盘选中运动场详情；首页故事不改变正常时刻。两秒车辆跟随帧采样 120 帧、P95 16.9ms，仅代表本机无头 Chromium。未验证真机或真实建筑外形。

# 前端改版验收记录

最新复验：2026-10-14（电影式动效改版）。[新增镜头截图与录屏](cinematic/README.md)。

验收日期：2026-10-14。运行方式：本机同源 HTTP 服务，独立 Chromium 测试浏览器。地图异常测试主动阻断外部请求，页面及 ECharts 从本地加载。

## 已验证

- JavaScript 语法通过；自有界面代码未发现 emoji、字符星星或字符箭头图标。图标、车辆与评分使用 SVG，历史文字和用户输入不做表情清洗。
- 三页覆盖 1920×1080、1366×768、1024×768、768×1024、390×844、360×800、844×390，21 个页面/视口组合未发现页面横向溢出。
- 深浅主题、桌面与手机截图已保存；视觉复核修正了首页场景定位、地图标签尺寸、手机地图与播放控件布局、导览控制区域。
- 30 / 60 / 120 帧率与 1× / 4× / 16× 的模拟推进结果一致；回拖、重播、整数分钟边界、未来工单过滤、20:00 停止及重新播放通过。
- 点位问题合并到开放工单，到站收运和工单完成同步；一般问题遵循 18 / 55 模拟分钟规则；建议、表扬不生成工单。
- 反馈可不评分；历史内容、回复和时间保留；提交、刷新、切页、从关联工单查看、二次确认清除通过。清除保留 8 条系统示例。
- 故事手动切换、自动播放、到站过程、跳步、返回、重播、退出和状态恢复通过；没有改写本机反馈。
- 手机点位/车辆列表、详情、车辆跟随、手动拖动退出跟随、图表、记录定位、时间轴和倍率操作通过。
- 键盘可选中 SVG 点位、调节时间轴；减少动态效果设置被正确读取，相关动画规则已关闭。
- 模拟后台可见性变化后不推进时间，返回不追赶；跨页保留播放标志，反馈页保持模拟时刻。
- 地图失败和加载后断网仍可用本地示意图选择点位、回放；存储写入失败显示错误，不显示提交成功；加载时忽略中断写入遗留的孤立工单。
- 连续 3 秒本机无头浏览器动画采样：181 帧，中位帧间隔 16.7ms，P95 为 16.8ms，没有超过 50ms 的帧。这是本机检查数据，不代表移动设备性能承诺。

机器可读结果：[业务逻辑](core-results.json)、[页面及交互](browser-results.json)、[动效与异常](motion-results.json)、[静态检查](static-results.json)。测试源码位于 `tests/`。

## 验证边界

- 允许网络连接的检查中，高德底图仍未成功加载，实际呈现为本地校园示意图；因此没有把真实高德底图、POI、第三方服务鉴权或其在线性能记为通过。[该次画面](map-network-check.png)
- 手机与平板检查使用浏览器视口模拟；未进行 iOS Safari、Android 真机、软键盘、安全区硬件或不同设备 GPU 性能验证。
- 后台暂停采用可见性事件模拟验证；不同操作系统的休眠、浏览器冻结与电源策略未逐一覆盖。
- 未进行完整屏幕阅读器审计。已验证关键键盘操作、焦点样式、状态文字及减少动态效果设置。
- 整站首次访问仍需取得本地服务器资源；没有加入 Service Worker 离线缓存。这里的断网检查指已加载页面可继续操作本地模拟功能。
- 当前仍是纯前端原型。地图轨迹、重量、分类准确率、处理进展和碳减排估算均不构成实际学校运营数据。

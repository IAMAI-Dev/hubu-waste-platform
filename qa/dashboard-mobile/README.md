# 移动看板专项验收

清运看板减少重复标题与工具行，选中对象后使用独立摘要卡，避免大详情被裁切并遮挡地图。展开详情时收起指标和视图页签，保留可滚动正文、固定操作头及回放。短屏、横屏分别安排地图与控制区。

## 运行

```powershell
python preview.py 8766
npm run test:dashboard-mobile
```

可通过 `HUBU_BASE` 指向其他同源预览服务。使用独立 Chrome 模拟触摸，不读取用户浏览器会话。

## 已验证

- 320×568、360×560、390×560、390×640、390×700、390×844、430×932、667×375、844×390，分别检查深浅主题。
- 18 组布局检查及 4 组交互检查全部通过，无页面脚本异常，原始结果见 [results.json](results.json)。
- 摘要完整显示且与地图不重叠；竖屏地图占满可用宽度，短屏自动让出指标空间。
- 车辆与点位摘要、展开、收起、关闭、跟随、时间轴、专注模式、图表返回及故事入口。
- 在线高德底图加载六个点位及三辆车辆；选中后视口随剩余地图区域调整，标签只突出选中车辆。
- 横竖屏与桌面断点切换后，导航与操作入口恢复正确位置。

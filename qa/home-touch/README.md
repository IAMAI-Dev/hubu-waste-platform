# 首页触摸滚动修复

移动端首页校园模型作为滚动故事的展示场景。关闭点位、车辆点击和键盘焦点，允许原生上下滚动与浏览器缩放；故事镜头、章节按钮、进入看板按钮及底部导航保留。桌面鼠标端继续支持点选，断点或输入类型改变时同步更新。

修复前：在 390×760 的右侧模型区域上滑 180px，`scrollY` 仍为 0。共享地图 SVG 的 `touch-action: none` 阻止了浏览器滚动；只设置外层容器不足以解决后代元素命中的问题。

## 验证

运行本地 HTTP 服务后：

```powershell
$env:HUBU_BASE = 'http://127.0.0.1:8766/'
node tests/home-touch.test.cjs
```

通过 Chrome DevTools Protocol 发送真实触摸序列，覆盖 320×568、390×640、390×760、390×844、768×1024、844×390、1024×768。

- 七种视口从模型右侧上滑，页面均前进 145px；反向滑动可返回。
- 在可见车辆与点位坐标处触摸，每种布局检查 6–9 个对象，均留在首页。
- 独立故事不修改看板共用进度；章节按钮、主按钮、底部导航正常。
- 减少动态效果仍可原生滚动；桌面点选车辆打开对应详情。
- 窗口从桌面切换平板再返回，模型交互随之切换。

# 手机专项验收

本轮保留森林绿视觉、四页入口、SVG 图标、校园模型和高德在线底图，优先调整手机操作布局。

## 变化

- 统一 60px 手机页头与底部四页导航；处理动态视口、安全区域和输入法，表单字号为 16px，主要操作目标为 44px。
- 清运看板按标题、四项指标、五个视图、地图及回放分区。详情支持展开/收起与独立滚动；校园模型支持单指移动、双指缩放，手动移动退出跟随。横屏使用左侧操作、右侧地图。
- 首页把故事文字和校园镜头重新分配到手机视口，五个阶段可触摸跳转，减少动态效果时呈现静态故事。返回页面时恢复活动场景；反馈页保留浏览器返回缓存中的表单内容。
- 投放页先显示紧凑的四类容器，校园地图按需展开；回放控件与内容页签可随滚动保持可用，补充可触摸的小时选择器。隐藏的校园模型停止逐帧绘制。
- 反馈表单优化键盘避让、筛选、评分和提交进度入口；数量统一收敛显示，避免长小数挤压手机布局。

## 结果

`tests/mobile.test.cjs` 共 28 项检查通过，机器结果见 [results.json](results.json)。其中包括四页 × 十种屏幕尺寸 × 深浅主题的 80 个页面组合，无横向溢出。

尺寸：320×568、360×640、360×800、375×667、390×844、412×915、430×932、667×375、844×390、932×430。

操作检查覆盖触摸章节及浏览器返回、详情展开、时间轴与倍率、图表和记录联动、拖动退出跟随、双指缩放、聚焦地图、四幕/六幕故事、监测小时选择、键盘缩小视口（含 390×300）、反馈提交、减少动态效果，以及高德地图六点位三车辆。

原有三页桌面/平板/手机浏览器回归和 12 项业务核心回归通过。原有反馈、工单和库存逻辑未改写。

## 重现与边界

运行 `python preview.py 8766`，另开终端执行 `npm run test:mobile`。可通过 `HUBU_BASE` 指定其他同源地址。

验收使用 Windows Chrome 的手机尺寸、触摸事件和视口缩小模拟，实际请求高德在线服务；未将其等同于 iOS Safari、微信内置浏览器、真实输入法或各型号手机性能的实机测试。发布后另核对 GitHub Pages 的当前版本和手机页面。

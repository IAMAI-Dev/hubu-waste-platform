# 全过程管理验收

本次扩展新增 `monitor.html`，并更新公共引擎、首页、看板详情、反馈类别和四页导航。

## 数据口径

- 四类容器总配置容量为每点位 780 L（240 / 240 / 60 / 240 L）。容量占用可超过 100%，超出部分表示积压，不能当作容器物理容量增大。
- 初始存量与逐分钟投放事件共同形成 FIFO 批次库存。午间 11:00—13:30 增加投放强度；类别序列和体积为确定性预设，不因刷新随机改变。
- 分类密度仅用于生成模拟重量，绝不代表摄像头精确称重。公斤和升各自对账，展示层保留一位小数，内部计算不舍入。
- 每次到站收运库存的 95%，剩余批次继续计龄。地图标记显示最高负荷类别，顶部总体占用按全部配置容量计算。
- 容量与暂存预警合并到当前未完成收运任务；满载 15 分钟后标为优先。异味、脏乱采用独立演示保洁进度，车辆经过不会替代保洁办结。
- 午间故事使用正常引擎的隔离状态，离开时恢复原时刻、速度、播放、选择和本机数据。

## 验证

- `tests/core.test.cjs`：12 项测试，含全天 841 个整数时刻的重量/体积守恒、部分收运保留年龄、满载与超时规则、不同帧率/倍率一致性、回拖重放、反馈兼容与存储失败、午间故事及保洁独立闭环。
- `tests/browser.test.cjs`：原有三页七种尺寸、12 张深浅主题桌面/手机截图、反馈闭环与清除确认、离线示意图、导览及减少动效回归。
- `tests/motion.test.cjs`：真实到站、后台暂停、跨页进度、终点停止与离线操作；本机 Chrome 地图动画采样结果见 `../motion-results.json`。
- `tests/monitor.test.cjs`：七种尺寸 × 深浅主题，全部三页签无横向溢出；手动/自动六幕、前后切换、重播退出、恢复原状态、跨页库存、刷新、数据说明和减少动效。机器可读结果见 `results.json`。

## 验证边界

浏览器验证使用 Windows Chrome 的桌面和移动视口模拟，并非真实手机触屏、Safari 或不同 GPU 的性能测试。本轮断开外部网络验证本地示意功能；未新增或验证真实摄像头、称重硬件、高德在线服务、学校实测数据或后端。
